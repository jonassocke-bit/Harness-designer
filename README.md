# Harness Designer V0.10 — iPhone Workbench

- resizable translucent bottom sheet with internal scrolling
- compact sheet state
- undo / redo history (up to 40 states)
- automatic local project snapshot in localStorage
- lock selected object

- haptic feedback for selection/history actions

- V0.9 stable strap frames, automatic crossings, ring wraps and surface geometry retained
