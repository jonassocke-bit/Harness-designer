# Harness Designer V3.5.3 – Update

Basis: V3.5.2 OUTSIDE + REPORT IMAGE

## Enthalten

- **Riemen-Mittelpunkt:** sichtbarer Mittelpunkt auf 50 % verkleinert, Touch-Hitbox bleibt groß.
- **Reset statt „− Punkt“:** setzt einen manuell verschobenen Riemen-Mittelpunkt / Routing-Guide wieder auf Auto zurück; bei Mirror-Paaren beide Seiten konsistent.
- **Breite Riemen > 20 mm:** zusätzliche Körperprüfung der Mittellinie vor und nach der finalen Kantenglättung.
- **Brust/Schulter:** Adaptive-Komplexität wird lokal angehoben, ohne High global zu erzwingen.
- **Kopf:** virtuelle äußere Kollisionshülle schließt kleine Hohlräume wie Augen-/Mundöffnungen für den Solver, ohne das sichtbare Mannequin zu verändern.
- **Arm-Zonen:** Schulter-Regler verschieben jetzt die vollständige Schulter→Achsel-Grenze; Achsel-Regler bleiben für lokale Feinjustierung.
- **UI-Cleanup:** alte gestapelte Build-/Versionsstrings werden entfernt; nur `V3.5.3` bleibt klein rechts unten.
- **Toolbox:** kompaktes Werkzeug-Icon; Mannequin-Anpassungen werden mit den Debug-/Solver-Werkzeugen zusammengeführt; separates Mannequin-Icon entfällt.
- **UI-Screenshot:** iOS/Safari-Fallback über DOM-Rasterung + frisch gerasterte WebGL-Szene statt SVG-`foreignObject`.
- **Guided Test:** bestehender V3.5.2-Lauf wird vor dem ersten V3.5.3-Test in der Historie archiviert und der neue Lauf frisch gestartet.

## Dateien

## Hinweis zum ersten Start

Wenn bereits ein V3.5.2-Guided-Test im Browser gespeichert ist, lädt V3.5.3 beim ersten Start **einmal automatisch neu**, nachdem der alte Testlauf archiviert wurde. Danach startet der V3.5.3-Test leer.
